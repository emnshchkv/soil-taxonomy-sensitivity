# Свидетельства библиографии

AI4Science-агент, 2026-11-17. Здесь сохранены библиографические данные и первичные тексты, без полного контекста прежней сессии и без файлов ключей.

- `openalex_search_*_restored.json`: семь реальных поисков предыдущего исполнителя, восстановленные из его локального журнала. Дата выполнения взята из `result.provenance.retrieved`; параметры и ответ сохранены. Восстановление не выдаётся за новый запрос.
- `openalex_W*_work.json`: семь новых публичных адресных HTTPS GET к OpenAlex, включая настоящие идентификаторы авторов. Это не `openalex_work` MCP и не вызовы модели.
- `verified_sources.json`: компактная сверка выбранных работ, локальных файлов, утверждений и подтверждения пользователя.
- `graph_files.json`: только новые страницы графа этой библиографической работы.
- `*_primary_access.json`, `*_bioc_access.json`: доступность и SHA256 первичных текстов. Ответ CAPTCHA не сохраняется как статья.
- `callahan2016_primary_bioc.xml`, `bolyen2019_primary_bioc.xml`: первичные тексты из официального сервиса PMC BioC. `balvociute2017_primary.html`: статья издателя. Остальные четыре текста остаются в `paper/`.

Библиография использует годы окончательных выпусков: GTDB 2022 и Greengenes2 2024. Исторические OpenAlex-поля 2021/2023 не переписывались. Пользователь 2026-11-17 подтвердил семь выбранных DOI: «Подтверждаю все семь DOI».

Эти материалы предназначены для локальной сверки; в архив подачи включаются только действительно необходимые файлы, без полного контекста журналов и без лишних копий литературных текстов.
