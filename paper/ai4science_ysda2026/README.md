## Сборка

Нужен TeX Live с pdfLaTeX, BibTeX, русским babel/T2A и пакетами предоставленного шаблона. Если команды доступны в PATH, из корня проекта:

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/build_article.py --log-dir results/article_step5/build_NEW
```

Если TeX установлен отдельно, передайте `--tex-bin <каталог-исполняемых-файлов>`. Скрипт меняет PATH только дочерних процессов, ничего не устанавливает. Текущая сборка использует уже существовавший временный TinyTeX; его абсолютный путь сохранён в журнале, но не требуется как постоянный путь проекта. Точный порядок из каталога статьи:

```sh
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
bibtex paper
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
```

## Проверки из корня проекта

Все команды Python выполняются с префиксом `conda run --no-capture-output -n qiime2-amplicon-2025.7`:

```sh
python3 src/check_paper_results.py --out-dir results/paper_step4/20261118
python3 src/check_literature_registry.py --article-dir paper/ai4science_ysda2026
python3 src/check_paper_scaffold.py
python3 src/check_article.py
python3 tests/test_article.py
python3 checks/check.py
python3 src/run_paper_step4_scientific_checks.py --log-dir results/article_step5/scientific_NEW
```

`check_article.py --draft` проверяет фактический исходник до PDF; его успех не означает финальной приёмки. Обычный режим требует PDF, библиографию, журнал сборки, реальные страницы, отсутствие неразрешённых ссылок и переполнений. Изолированные испытания меняют временные копии и обязаны обнаружить подмены чисел/ссылок/разделов/таблиц/происхождения. Полноту смысловой поддержки отдельно проверяет агент и затем автор.

Научный runner запускает существующие проверки исходного сравнения, семейственных профилей/self-test, точного совпадения DADA2, каркаса, литературы и общего проекта. Полный исходный верификатор DADA2 должен сохранять отдельный `INCOMPLETE/2` по Kr5; успех runner означает соответствие этим ожидаемым исходам, а не устранение ограничения.

Итог: 11 страниц PDF, из них 4 страницы основной части (текст до страницы 3 и обе таблицы на странице 4); литература и ИИ — страница 5, приложение — страницы 6–11. Все страницы просмотрены. Финальная проверка: PASS/0, 646 сверок статьи плюс 1520 сверок числового комплекта; 14 изолированных испытаний дали ожидаемые исходы. Полный DADA2 отдельно сохраняет INCOMPLETE/2 по Kr5.

Актуальные журналы в `results/article_step5/`: `20261118/` — вспомогательный экспорт; `reading_final_20261118/` — синтез чтения финальных исходников; `build_20261118_layout/` — успешная окончательная сборка; `verification_20261118/acceptance.json` — сводная приёмка, `article_final_layout.json`, `article_mutations_layout_retry1.json`, `visual_review.json` и `scientific/verification.json` — детальные свидетельства. Первые попытки сохранены отдельно; ошибка декодирования TeX-log устранена байтовым чтением, дефект длинного колонтитула устранён и включён в проверку.

Стандартная сноска шаблона о подаче заменена только текстом локального неподанного черновика в preamble; исходный .sty, обезличенный режим, поля и шрифты сохранены. После основной части raggedbottom предотвращает растягивание библиографии; два табличных блока объединены в один float. Чтение вслух синтезировано в AIFF голосом Milena, воспроизведение динамиками и человеческое прослушивание не заявляются. Человеческое принятие текста остаётся за исследователем.
