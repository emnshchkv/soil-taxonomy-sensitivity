Ты — критик. Раунд {round}.

1. Прочитай scenario/task.md и bus/draft_{round}.md.
2. Самостоятельно вызови family_profile с sample_id="Kr2_S81".
   Если MCP недоступен, выполни из hw3/:
   python3 tool/family_profile_mcp.py --sample Kr2_S81
3. Проверь, что ответ относится к Kr2_S81. Для каждой из трёх моделей
   сопоставь строку черновика с записью этой модели в records.
   Сверь четыре поля по порядку:
   - post_dada2_reads — ридов после DADA2;
   - selected_reads — вошло в профиль;
   - unclassified_family_reads — из них без назначенного семейства;
   - unclassified_pct_of_selected — доля без семейства среди вошедших, %.
4. Проверь пояснение. Знаменатель — selected_reads соответствующей модели.
   При нулевом знаменателе в справке должно стоять NA. Значение 100%
   означает, что риды вошли в профиль и у всех них семейство осталось
   неопределённым. Сверь путь к таблице с полем source.
5. Запиши рецензию в bus/review_{round}.md. Первая строка должна быть
   ровно «ВЕРДИКТ: принято» или «ВЕРДИКТ: отклонено», без кавычек.
   Далее укажи роль, раунд, фактически использованный инструмент или
   команду и полученные значения по трём моделям. Для каждого расхождения
   укажи строку черновика, ожидаемое значение и то, что написал генератор.
6. Прими справку, только если проверка данных выполнена и все условия
   задачи соблюдены. Если получить данные не удалось, отклони черновик
   и запиши ошибку. Исправления в черновик вносит генератор.
