Шаги 1–4 практики недели 10, 2026-11-18. Этот файл задаёт устройство проекта и границы подготовки. После каркаса и постановки пользователь поручил оформить рабочий реестр ранее выбранной литературы, сохранив подтверждение семи DOI и проверив цитаты исторической версии статьи. Восстановление и написание рукописи остаются отдельным шагом. Текст создан агентом по существующим файлам и истории; содержательное принятие глоссария, постановки и сопоставлений литературы остаётся за исследователем.

При будущей подготовке требуется согласовать стиль, пути и проверку библиографии; копирование учебного проверяющего скрипта само по себе не даёт корректной проверки существующего формата. Оригинальные шаблоны не меняются.

## Команды и области их действия

Из корня проекта, без повторных научных расчётов:

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/check_paper_scaffold.py
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/check_literature_registry.py
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 checks/check.py
```

Первая команда: PASS/0 означает структурно проверенный каркас; FAIL/1 перечисляет нарушения. После разрешения шагов 2–3 постановка и литература допускают `state: draft` наряду с прежним `deferred`. `--layout-only` проверяет только устройство каркаса и явно исключает глоссарий. Ни один режим не проверяет содержательную полноту, научную истинность терминов, человеческое принятие, объём статьи или готовность к подаче.

Вторая команда проверяет реестр, сохранённые метаданные и хеши, а также буквальные ключи цитирования во всех TeX-файлах сохранённой версии. Отсутствие текущей рукописи явно отмечается `absent_not_checked` и не выдаётся за её приёмку. Если рабочая рукопись появится, её ключи также проверяются; `--article-dir <путь>` требует указанный комплект и возвращает INCOMPLETE/2 при его отсутствии. Макросы TeX не исполняются, содержательные утверждения проверяются по первичным текстам отдельно.

Третья команда сохраняет прежний критерий подготовки, денойзинга и классификации. Полный результат сравнения проверяется отдельно:

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/check_taxonomy_comparison.py --out-dir results/taxonomy_comparison/finish_20261116/main
```

Проверка текущих семейственных профилей:

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/check_prokaryotic_families.py --out-dir results/taxonomy_barplots/prokaryote_family_20261118_final
```

Полный `checks/verify_denoising.py` сохраняет отдельный INCOMPLETE/2 из-за сохранности Kr5 ниже установленного порога; `src/check_exact_match.py` проверяет техническую повторяемость с согласованным исключением. Успех других проверок не отменяет этот вердикт. Первоначальные критерии не меняются для получения PASS.
