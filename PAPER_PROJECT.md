Срез рабочего дерева перед этой задачей: `4b4c216` (2026-11-18, размещение картинок и кода). В `712e132` завершены диагностика Kr и семейственные профили; код окончательных рисунков — `24ec42e`. Прежний набор только Bacteria сохранён как исторический и описан в [BACTERIA_ONLY_20261118.md](results/taxonomy_barplots/BACTERIA_ONLY_20261118.md).

История прежней статьи сохранена в ветке `backup/article-before-pause-20261118`; восстановление не выполняется. Чтение её README подтверждает наличие прежних исходников, библиографии, числовых макросов, PDF и локального комплекта подачи. В README и `bibliography_review.md` сохранено подтверждение пользователем семи DOI от 2026-11-17. Их повторное подтверждение для того же списка не требуется. Авторские сведения также были предоставлены. Старые проверки относятся к прежнему комплекту, до новых изображений; готовность нынешней статьи из них не следует. Отправка в прежней истории не выполнялась.

Локальный `ai4science_ysda2026_template/` использует пакет `.sty` и BibTeX. Каркас `paper_project_skeleton/` использует другой класс `.cls` и проверку встроенных `\\bibitem`. При будущей подготовке требуется согласовать стиль, пути и проверку библиографии; копирование учебного проверяющего скрипта само по себе не даёт корректной проверки существующего формата. Оригинальные шаблоны не меняются.

## Команды и области их действия

Из корня проекта, без повторных научных расчётов:

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/check_paper_scaffold.py
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 checks/check.py
```

Первая команда: PASS/0 означает структурно проверенный шаг 1; FAIL/1 перечисляет нарушения. `--layout-only` проверяет только устройство каркаса и явно исключает глоссарий. Ни один режим не проверяет научную истинность терминов, человеческое принятие, объём статьи или готовность к подаче.

Вторая команда сохраняет прежний критерий подготовки, денойзинга и классификации. Полный результат сравнения проверяется отдельно:

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/check_taxonomy_comparison.py --out-dir results/taxonomy_comparison/finish_20261116/main
```

Проверка текущих семейственных профилей:

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/check_prokaryotic_families.py --out-dir results/taxonomy_barplots/prokaryote_family_20261118_final
```

Полный `checks/verify_denoising.py` сохраняет отдельный INCOMPLETE/2 из-за сохранности Kr5 ниже установленного порога; `src/check_exact_match.py` проверяет техническую повторяемость с согласованным исключением. Успех других проверок не отменяет этот вердикт. Первоначальные критерии не меняются для получения PASS.

## Границы следующих шагов

- Шаг 2: оформить постановку статьи из предварительно записанной методики, сохранив даты и описательный дизайн. Новые гипотезы не датировать задним числом.
- Шаг 3: по отдельному поручению использовать проверенные материалы резервной библиографии, согласовать реестр и цитаты.
- До возобновления статьи: проанализировать новые изображения и определить, какие выводы допустимы и какие таблицы/рисунки войдут в текст.
- Шаги 4–6: после отдельного поручения подготовить актуальный комплект доказательств, текст, сборку и полную проверку статьи; подача — отдельное действие.

Эти пункты задают места продолжения, а не поручают выполнять их сейчас. Глоссарий, правила и схема должны быть прочитаны исследователем; агент не ставит статус «принята» автоматически.
