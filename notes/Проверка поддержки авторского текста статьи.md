# Проверка поддержки авторского текста статьи

2026-11-18. [[src/check_article.py]] принимает непустые \napisano и \porozhdeno. Утверждение должно целиком находиться в пометке авторства; одновременное полное охватывание двумя разными видами отклоняется. Источники, карта, макросы, числовые литералы и цитаты проверяются одинаково для обоих видов. \istochnik сохраняет требование ссылки и не заменяет авторство. Реального автора скрипт не устанавливает: это заявленная пользователем разметка.

В [[paper/ai4science_ysda2026/claims.tsv]] добавлено авторское A02 с основаниями мотивации; сопоставимость исследований не выдана за проверенный эмпирический результат. [[paper/ai4science_ysda2026/ai_usage.tex]] и [[paper/ai4science_ysda2026/section_review.md]] отражают вставку A02 и редактуру A01. Авторская аннотация сохранена побайтно относительно начала задачи; принятие всей статьи человеком не заявлено.

По указанию пользователя «не пересобирай пока, я буду еще правки делать» PDF не пересобирался и сохранён побайтно. Для текущей редактуры используются --draft у проверки и --draft-only у регрессий. Полный режим по-прежнему требует актуальный PDF. README и WRITING описывают оба режима.

## Результаты

Проверки ниже относятся к срезу исходников на момент их запуска. После успешных тестов обнаружена продолжающаяся пользовательская редактура sections/problem.tex; агент её не менял и в свой коммит не включает. Для последующих правок потребуется повторить --draft; прежний PASS не заявляется проверкой ещё редактируемого текста.

Все Python-команды выполнялись через conda run --no-capture-output -n qiime2-amplicon-2025.7; q2cli version 2025.7.0.
