Для каждой указаны ключ, DOI/OpenAlex, библиографические данные, утверждение из первичного текста, локатор, отличие проекта и происхождение сверки. BibTeX — [[lit/references.bib]], неизменённые ответы OpenAlex и первичные XML/HTML — lit/evidence/20261117/.

Содержательная сверка выполнена отдельно по первичным текстам и сжатиям RESCRIPt. Уточнён локатор: Abstract RESCRIPt — PDF с. 1, Author summary — с. 2; исторические свидетельства не переписывались. Обобщение сжатия о primer-trimming не перенесено с COI на наш 16S. Онлайн-годы 2021/2023 и годы выпуска 2022/2024 для GTDB/Greengenes2 различены. [[src/check_literature_registry.py]] читает сохранённую версию статьи через Git из 37254a5a90a3efe5b4c6ca22e38c2e2066767178 без восстановления. Все находятся в разделе «Место в области» paper.tex, строки 44 и 46; paper_final.tex подключает этот текст. Точные локации — [[results/paper_scaffold/step3_20261118/literature.json]].

Скрипт не исполняет макросы TeX; после появления новой редакции проверка повторяется. Явно указанный отсутствующий --article-dir даёт INCOMPLETE/2.
