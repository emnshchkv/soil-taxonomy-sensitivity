# Набор готовых таксономий для сравнения

Готовые назначения SILVA, GTDB и Greengenes2 для одних 3374 ASV первого технического запуска DADA2; таблица частот содержит 11 образцов. Числа и контрольные суммы входов зафиксированы в [[METHOD_COMPARISON.md]]; исходный этап классификации описан в [[reports/Готовность к классификации]].

Для профилей используются только 10 почвенных образцов: Kr1_S80–Kr5_S84 и LUB2_S92–LUB6_S96. K_S63 — отрицательный контроль, не входит в почвенные профили. Назначения сохраняются для всех ASV; невзвешенные почвенные показатели используют ASV с положительной суммарной частотой в десяти почвах. Пересечения с контролем не исследуются.

Kr5_S84 сохраняется в анализе. Его выход 1505 из 60078 ридов (2.51%) — заранее записанное ограничение, не основание для новой фильтрации в этом сравнении. DADA2 и классификация для этапа сравнения повторно не запускаются. Все три таксономии получены с confidence=0.7; праймеры и регион обучения моделей не установлены.
