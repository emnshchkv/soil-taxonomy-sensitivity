# Параметры денойзинга (решение человека)

Заполняется до запуска `dada2 denoise-single`. Две строки ниже читает `checks/check.py`: они должны начинаться с начала строки и содержать целые числа.

trim-left: 20
trunc-len: 200

## Обоснование
- Дата и по какому графику выбрано (`results/quality_by_sample.png`): 2026-11-04, по графику профилей качества всех 11 образцов
- Длина прочтений R1 (из `results/read_counts_R1.tsv`): 251 нуклеотид
- Праймеры удалены из ридов? Если нет — `trim-left` равен длине праймера: нет, длина 20 (V4–V5)
- На какой позиции медианное качество падает ниже выбранного порога и какой порог: медианное качество стабильно Q≥30 до позиции ~200, затем снижается; выбран порог Q≥20
- Какая доля ридов сохраняется при этих значениях (после запуска, из `dada2_stats.qzv`): <заполнить после денойзинга>

Одни и те же значения применяются ко всем 11 образцам, включая контроль `K_S63`. Остальные параметры — как в пайплайне пользователя: `--p-max-ee 3`, `--p-min-fold-parent-over-abundance 2`.

## Исключение по сохранности Kr5_S84
Пользователь разрешил завершить три повтора 20/200, несмотря на известную положительную сохранность Kr5_S84 ниже 30%. Это исключение зафиксировано. Нулевой выход почвенного образца или новые нарушения требуют остановки.
