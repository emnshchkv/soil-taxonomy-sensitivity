# План исправления и проверки верификатора

Исходная версия: 6ce5404. Протокол METHOD.md §§0–7 (a398c5f) не меняется. План фиксируется до испытаний исправленной реализации. Предыдущие результаты известны; эта работа — проверка исправления, а не новый слепой эксперимент DADA2.

1. Читатель QZA: настоящие BIOM/HDF5, FASTA, TSV и action.yaml; проверка типов, идентификаторов, параметров, входа и версий. Проверить на архивных реальных выходах независимым Artifact.load/validate/view из установленного QIIME 2. Артефакты не возвращать в work/.
2. Чистая validate(dataset): согласованность ключей, конечные целые неотрицательные частоты, длины, баланс, невозрастающая статистика, provenance и попарное сравнение по последовательностям. Повторный вызов не изменяет аргумент.
3. Самотест: все случаи METHOD.md §5; при повреждении данных ожидается конкретный смысловой код. Перенос одного рида в третьем повторе даёт REPEAT_DIFFERENCE при сохранённом балансе. Исправление восстанавливает PASS. Все мутации только во временных копиях.
4. Свойства на четырёх разных размерах матрицы: порядок строк/столбцов/FASTA; согласованное переименование ASV; баланс по каждому образцу; невозрастание счётчиков; целочисленность/неотрицательность/конечность; обнаружение переноса с сохранённой суммой. Синтетические образцы отделены от настоящих.
5. Качество: Q10,Q30 дают Q25=15, Q50=20, Q75=25. Ошибка Q50=21 — QUALITY_VALUE. Действительно читать и сверять сохранённые TSV; отдельно проверить изменение сводного показателя и позиционного значения, дубликаты и отсутствие файлов. Независимый алгоритм — гистограмма Phred и интерполяция порядковых статистик.
6. При одновременно известных нарушениях и недостающих входах результат FAIL/1; только недостающие входы — INCOMPLETE/2. Низкая положительная сохранность не отменяется этой задачей.
7. Перед испытаниями сохранён манифест SHA256 и прав data/, work/, прежних results/, checks/check.py, memory/denoise_choice.md, METHOD.md и ontology.yaml. После испытаний каждое значение и состав data/, work/ должны совпасть. Новые журналы разрешены в results/. checks/ вновь только для чтения.

Успех этой задачи — все перечисленные испытания пройдены, а не полный научный PASS: профили и три новых запуска пока отсутствуют. Используются локальные архивные QZA/профили только как тестовые входы читателей. Публичный самотест от частных архивов не зависит.
