## Заключительные разделы (с. 30–32)

Данная часть содержит финальные разделы статьи [с. 30]. Страница 30 включает описание дополнительных материалов: рисунок S2 Fig демонстрирует сравнение качества фильтрации базы данных SILVA при таксономической классификации последовательностей Earth Microbiome Project [с. 30], а также ссылку на Jupyter notebook для конструирования референсной базы данных 12S рРНК [с. 30]. Далее следуют благодарности разработчикам QIIME 2 и подробный перечень вклада авторов по категориям CRediT (conceptualization, data curation, formal analysis, investigation, methodology, project administration, resources, software, supervision, validation, visualization) [с. 30–31]. Страницы 31–32 содержат продолжение описания вклада авторов и библиографический список из 38 источников, охватывающих работы по таксономии бактерий, базам данных рРНК (SILVA, Greengenes, RDP), метабаркодированию и филогенетическому анализу [с. 31–32].
