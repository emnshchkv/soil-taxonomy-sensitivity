# Таксономические барплоты: картинки, код и данные

Текущий набор — **семейства бактерий и архей** по SILVA, GTDB и Greengenes2. Назначенные семейства с долей не менее 2% в конкретном образце выделены цветом, меньшие назначенные доли объединены серым, неопределённое семейство показано отдельно.

## Быстрый доступ

| Что нужно | Где открыть |
|---|---|
| Готовые картинки всех моделей и общего обзора | [figures/taxonomy/family/](../../figures/taxonomy/family/README.md): PNG, PDF и SVG |
| Код и команды запуска | [src/TAXONOMY_BARPLOTS.md](../../src/TAXONOMY_BARPLOTS.md) |
| Полные таблицы, отбор, знаменатели и проверки | [Окончательный результат](prokaryote_family_20261118_final/README.md) |
| Почему Kr почти не определены, а SILVA Kr2/Kr5 пусты | [Диагностика до исходных ASV](kr_diagnostics_20261118/README.md) |

Картинки в `figures/taxonomy/family/` — побайтные копии окончательного запуска. Оригиналы остаются внутри каталога запуска для воспроизводимости; [манифест копий](../../figures/taxonomy/family/manifest.json) связывает обе папки и контрольные суммы. Скрипты уже отслеживаются в `src/`, исходные QZA остаются локальными в `work/qza/`.
