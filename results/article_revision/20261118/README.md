# Численные дополнения после замечаний к статье

Экспорт из сохранённых результатов, без повторного денойзинга, классификации и основного расчёта сравнения. Генератор: `src/prepare_article_revision.py`. Входы и выходы зафиксированы по SHA256 в `manifest.json`; структура и границы сводок — `summary.json`.

- `kr_filter_reasons.tsv`, `kr_filter_table.tex`: взаимоисключающее разбиение ридов пяти Kr по SILVA на Eukaryota, неизвестный домен, явные органелльные назначения среди Bacteria/Archaea и оставшиеся Bacteria/Archaea. Перенос из `results/taxonomy_barplots/prokaryote_family_20261118_final/filter_counts.tsv`. «Органеллы» означает точную метку Mitochondria/Chloroplast на любом ранге; отсутствие метки не доказывает отсутствие органелльного происхождения. Эти назначения не являются независимым установлением биологической истины.
- `genus_conditional.tsv`: для каждой пары — число разных ASV, назначенных обеими моделями до рода во всём почвенном наборе; число образцов с ненулевым знаменателем; медиана условной доли совпадения, взвешенной ридами по образцам. Общий ASV-знаменатель не равен сумме знаменателей образцов.
- `genus_conditional_per_sample.tsv`, `genus_denominators_table.tex`: знаменатели по каждому образцу в ASV и ридах. При нулевом числе совместно назначенных ридов доля равна NA, а не нулю; такие образцы не входят в медиану. Исходные количества ридов сверены с `pairwise_match_per_sample.tsv`; ASV-знаменатели получены пересечением признаков назначения в `assignments.tsv` с ненулевыми частотами BIOM.
- `control_summary.tsv`, `control_overlap.tsv`, `control_shared_asv.tsv`: контроль K_S63 до/после DADA2, число его ASV и пересечение с объединением почвенных ASV. Это пересечение идентификаторов, не доказательство загрязнения, его источника или направления переноса. Ни один ASV на основании пересечения не удалялся. Число сохранённых ридов сверено с `dada2_stats.qza`, входных — с `read_counts_R1.tsv`.
- `method_parameters.tsv`: порог сохранности ридов извлечён из условий обоих существующих верификаторов; результаты и сами критерии не изменялись.
- `numbers.tsv`, `numbers.tex`: 56 макросов Revision с точными источниками и селекторами. Медианы долей экспортированы в проценты с HALF_EVEN до двух десятичных знаков.

Сравнение полных линий в исходной методике чувствительно к регистру: ключи сравниваются через `==` после удаления лишних краевых пробелов. Без учёта регистра проверяются отдельные служебные метки органелл и точное терминальное `uncultured` в дополнительных семейственных профилях. Эти разные операции нельзя смешивать.

История в `audit/numeric_attempt01/` сохраняет первую попытку с ошибочным описанием совпадения как регистронезависимого и соответствующим дополнительным пересчётом. После исправления `casefold()` на `==` все численные TSV, макросы и таблицы этой попытки совпали побайтно; исправилось определение в summary. `audit/numeric_attempt02/` — промежуточный корректный численный комплект с суммарной таблицей знаменателей; в окончательном комплекте эта таблица развёрнута по всем образцам. Текущими являются файлы непосредственно в этом каталоге.

Воспроизведение из корня проекта в новый каталог:

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/prepare_article_revision.py --out-dir results/article_revision/reproduction_NEW
```

Генератор отказывается перезаписывать собственные существующие выходные файлы; соседние журналы в каталоге допускаются. Независимую проверку выполняет `src/check_article_revision.py`, который не импортирует генератор.
