# Полная проверка путей литературы

2026-11-18: по последующему поручению пользователя проверены все текстовые файлы, включая скрытые и игнорируемые (`rg -uuu`). Исключены внутренности Git и бинарные артефакты. Собственный каталог аудита содержит снимки поиска и исключён из рекурсивного повторного поиска; эти снимки являются историей проверки.

Исправлены адреса в старом промпте, трёх заметках и тестовых примерах. В рабочей навигации и новом промпте указан references. Сами публикации не изменялись. Рукопись и её шаблон сохраняют имена paper.tex/paper.pdf; названия скриптов подготовки статьи также не относятся к прежнему каталогу литературы.

- [scan_before.json](scan_before.json) — исходный поиск и точная команда.
- [changes.json](changes.json) — изменения и контрольные суммы сохранённых файлов.
- [scan_after.json](scan_after.json) — классификация оставшихся вхождений: 188 строк в 44 файлах; 47 строк с прежним именем каталога относятся к истории и учебному каталогу рукописи. Устаревших рабочих путей нет.
- [verification.json](verification.json) — команды и коды проверки реестра, его пяти тестов, каркаса, числового комплекта и общей проверки: все 0; новый SHA промпта.

Исторические local/local_path в evidence не используются для открытия текущих файлов. Для этого служат primary_files[].current_path в [манифесте](../../../lit/transfer_manifest.json) и ссылки [реестра](../../../lit/lit.md). Сохранённые снимки сверяются с Git и SHA; original_path, старые baseline, прошлый дневник и поля old/from описывают реально существовавшее размещение. Их замена исказила бы происхождение.

Семь текущих первичных источников найдены и совпадают по SHA256; 123 файла литературы, свидетельств и прежних результатов проверок сохранены. Проверка не является приёмкой отсутствующей статьи.
