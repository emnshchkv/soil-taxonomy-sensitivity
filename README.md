# Чувствительность таксономического профиля бактериальных сообществ городских почв Москвы к выбору классификатора и референсной базы данных

## Цель

Выяснить, насколько таксономический состав бактериальных сообществ почв Москвы (16S рРНК, регион V4–V5, QIIME 2 2025.7) и выводы о нём зависят от классификатора и референсной базы при фиксированной обработке ридов.

**Текущий этап** — всё до сравнения классификаторов: подсчёт ридов, импорт и сводка качества, денойзинг (DADA2), классификация тремя методами `classify-sklearn` на базах SILVA 138, GTDB и Greengenes2 (порог по умолчанию, `confidence 0.7`). Само сравнение методов на этом этапе не делается.

**Данные:** 11 образцов, анализируются как single-end (только R1). Десять почвенных: Крылатское (Kr1–Kr5) и Люблино (LUB2–LUB6). Один отрицательный контроль, амплифицированная вода (`K_S63`).

**Граф проекта.** Проект ведётся как хранилище Obsidian: каждый файл — узел, ссылки `[[…]]` — рёбра, схема графа задана в `ontology.yaml`. Задачи ставятся агенту словами, он записывает их в `tasks/`, выполняет по подзадачам и достраивает граф. Малая цель графа — подсчёт ридов и оценка их качества.

## Что где лежит

### Корень: правила, состояние, журнал

| Файл | Что это |
|---|---|
| `AGENTS.md` | Договор с ИИ-агентом: цель, критерий готовности, правила ведения графа, запреты, протокол работы |
| `ontology.yaml` | Онтология графа: классы, отношения, атрибуты, правила |
| `INDEX.md` | Карта проекта для агента |
| `STATUS.md` | Текущее состояние: где работа, что дальше, какие ограничения действуют; перезаписывается целиком |
| `diary.md` | Журнал сессий; только дописывается |
| `cascade.sh` | Вспомогательный скрипт, добавлен вместе с `paper.txt`; назначение `<уточнить>` |
| `.gitignore` | Исключает из git данные, артефакты `work/` и статьи |

### Граф

| Папка | Что внутри |
|---|---|
| `tasks/` | Заметки задач и подзадач: запрос, «Готово, когда», «Не входит», статус, «Итог» |
| `notes/` | Заметки объектов: образцы, наборы данных, методы, эксперименты, результаты, проверки, источники, авторы, запросы к OpenAlex и Wikidata |
| `ontology/` | По одной заметке на каждый класс онтологии |
| `reports/` | Отчёты, которые написаны по просьбе человека |
| `.obsidian/` | Настройки хранилища: показ всех файлов, цвета узлов графа |

### Данные и результаты

| Папка | Что внутри |
|---|---|
| `data/raw/` | Сырые риды `*.fastq.gz`, R1 и R2 по каждому образцу, и `raw.sha256`; только чтение |
| `data/meta/` | Манифест (`fq-manifest-single.tsv`) и метаданные образцов (`metadata.tsv`) |
| `data/refs/` | Готовые классификаторы SILVA 138, GTDB r220, Greengenes2 и `VERSIONS.md` (источник, дата, sha256) |
| `work/` | Артефакты QIIME 2: `qza/` (данные), `qzv/` (визуализации) |
| `results/` | Итоговые таблицы, например `read_counts_R1.tsv` (число и длина ридов по образцам) |
| `src/` | Скрипты, например `count_reads.py` |

### Проверка, окружение, литература

| Папка | Что внутри |
|---|---|
| `checks/` | `check.py` — проверка готовности этапа; только чтение |
| `env/` | Окружение conda `qiime2-amplicon-2025.7`: `environment.yml`, `explicit.txt` |
| `memory/` | `denoise_choice.md` — решение человека по `trim-left` и `trunc-len`; конспекты статей (`L1`–`L3`) и `state.md` |
| `paper/` | PDF статей по теме и их разбивка на части (`parts/`) |
| `library/` | Тексты найденных источников; появляется, когда агент скачивает открытые версии |
