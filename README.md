# Чувствительность таксономического профиля бактериальных сообществ городских почв Москвы к выбору классификатора и референсной базы данных

## Цель

Выяснить, насколько таксономический состав бактериальных сообществ почв Москвы (16S рРНК, регион V4–V5, QIIME 2 2025.7) и выводы о нём зависят от классификатора и референсной базы при фиксированной обработке ридов.

**Состояние:** подготовка ридов, проверка трёх технических повторов DADA2 и классификация 3374 ASV тремя готовыми моделями выполнены. Этап 4 завершён: существующие назначения и профили сравнены по заранее записанной `METHOD_COMPARISON.md`, результаты проверены и воспроизведены. Один алгоритм `classify-sklearn`, три референсные модели, `confidence=0.7`. Итоговая экологическая интерпретация — следующий этап.

**Данные:** 11 образцов, анализируются как single-end (только R1). Десять почвенных: Крылатское (Kr1–Kr5) и Люблино (LUB2–LUB6). Один отрицательный контроль, амплифицированная вода (`K_S63`).

**Граф проекта.** Проект ведётся как хранилище Obsidian: каждый файл — узел, ссылки `[[…]]` — рёбра, схема графа задана в `ontology.yaml`. Задачи ставятся агенту словами, он записывает их в `tasks/`, выполняет по подзадачам и достраивает граф. Малая цель графа — подсчёт ридов и оценка их качества.

## Сравнение таксономических профилей

Методика: [METHOD_COMPARISON.md](METHOD_COMPARISON.md). Результаты и полные журналы — `results/taxonomy_comparison/finish_20261116/`; отчёт — [Сравнение таксономических профилей](reports/Сравнение%20таксономических%20профилей.md).

Проверка сохранённого результата (нужны локальные частные входы):

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 src/check_taxonomy_comparison.py --out-dir results/taxonomy_comparison/finish_20261116/main
```

Независимо доступные синтетические испытания:

```sh
conda run --no-capture-output -n qiime2-amplicon-2025.7 python3 tests/test_taxonomy_comparison.py
```

Сравниваются буквальные назначения с полной известной родословной; различия номенклатуры не приравниваются к биологическим ошибкам. Почвенные показатели рассчитаны для десяти образцов, контроль исключён. Kr5_S84 сохранён с ограничением 1505/60078 ридов (2.51%). Потери и пересечения контроля не исследовались. Технический PASS не устанавливает лучшую модель или биологическую правильность.
