# Проверить комплект результатов для статьи

Готово, когда: независимая проверка сверяет комплект с исходными таблицами и допускает только обоснованное округление; изолированные испытания обнаруживают подменённое число/знаменатель/пропуск и дают 0 на верном комплекте; полная проверка существующего сравнения, проверка семейств и checks/check.py дают 0; сохранность научных входов подтверждена, статус полного денойзинга и отсутствие текущей статьи отражены явно; журнал, карта и состояние обновлены.
Не входит: исправление исходных научных результатов ради прохождения проверки; изменение INCOMPLETE полного денойзинга; проверка отсутствующей рукописи как готовой статьи.
