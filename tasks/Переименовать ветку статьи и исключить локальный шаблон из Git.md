# Переименовать ветку статьи и исключить локальный шаблон из Git

Запрос пользователя: «почему ветка называется codex? переименуй, пусть просто будет `article`
папку с шаблоном я переметисла в репозиторий, сделай, чтобы она была неотслеживаемой.
какие следующие шаги нужно предпринять для написания статьи?»

Готово, когда: текущая ветка называется article; каталог ai4science_ysda2026_template/ исключён через .gitignore, в индексе Git нет его файлов и локальные файлы сохранены; действующий промпт указывает новую ветку и локальный путь; определены следующие шаги статьи; checks/check.py возвращает 0.
Не входит: запуск агента и написание статьи, новые научные расчёты, установка TeX, изменение содержимого шаблона, чужих файлов и исторических записей, публикация и push.

## План
Переименовать текущую ветку и исключить локальный шаблон из Git.
Обновить действующие указатели и проверить изменения.
Записать следующие шаги с учётом дневного бюджета токенов.

## Итог
Текущая ветка переименована в article. В .gitignore добавлено /ai4science_ysda2026_template/; все 11 файлов игнорируются, не отслеживаются и сохранили SHA256.
Действующий промпт, INDEX.md и ссылки памятки обновлены на локальный шаблон и ветку article. Следующие шаги сохранены в [[Проверка ветки article и исключения шаблона из Git]].
Адресная проверка через conda run python3 — PASS/0; checks/check.py — «ПРОВЕРКА ПРОЙДЕНА», exit 0. Агент, научные расчёты и сборка статьи не запускались.
