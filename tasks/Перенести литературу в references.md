# Перенести литературу в references

Запрос пользователя: «давай переименуем папки, пусть литература лежит в папке references?»

Готово, когда: каталог paper/ перенесён в references/ без изменения содержимого; рабочие ссылки, current_path реестра и исключение PDF из Git обновлены; сохранены исторические пути/свидетельства; проверки реестра, каркаса и checks/check.py проходят.
Не входит: перенос lit/ или manuscript/, изменение литературы, научных результатов, старых журналов, написание статьи.
