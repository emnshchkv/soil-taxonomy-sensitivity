# Провести сравнение и воспроизведение таксономий

Готово, когда: results/taxonomy_comparison/ содержит назначения по ASV и рангам, правила нормализации/сопоставления, покрытие, пять категорий попарного совпадения, частоты и доли профилей, расстояния по образцу/рангу/паре, сводную таблицу, манифест входов с UUID/SHA256 и версией кода, README со всеми столбцами и знаменателями; сохранены точные команды, полный stdout/stderr, коды завершения и времена с первого запуска; расчёт воспроизведён из чистой копии зафиксированного коммита с подключением частных входов только для чтения и сохранением новых выходов отдельно; таблицы сравнены по ключам и значениям с допуском 1e-12; SHA256 исходных входов зафиксированы до и после.
Не входит: повторный DADA2 или классификация, итоговые экологические выводы, выбор «лучшей» модели.
