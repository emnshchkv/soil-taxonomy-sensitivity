# Подсчитать риды и оценить их качество

Запрос пользователя: «Посчитай, сколько ридов в каждом образце, и оцени качество ридов»

Готово, когда: (а) `results/read_counts_R1.tsv` содержит 11 строк со столбцами из раздела 0 и `reads_R1 == reads_R2` у каждого образца; (б) для каждого образца число ридов R1 равно `gzcat <файл R1> | wc -l`, делённому на 4, расхождение 0 — команда и результат записаны в «Итог»; (в) `qiime tools validate work/qzv/reads_summary.qzv` сообщает success, а числа ридов по образцам в сводке равны таблице из (а).
Не входит: выбор `trim-left` и `trunc-len`, денойзинг, классификация; перезапись существующих `results/` и `work/` без подтверждения (если файл есть — проверь его, а не пересоздавай).

## Итог
Все 3 подзадачи выполнены. `results/read_counts_R1.tsv` — 11 образцов, `reads_R1 == reads_R2` у всех. Независимая проверка gzcat — расхождение 0. QIIME demux summarize — валидация ok, числа совпадают. Качество ридов: все 251 нт, медиана Q32–39, спад до Q14–17 на последних позициях. Остановка: человек выбирает `trim-left` и `trunc-len` для денойзинга.

Принято пользователем: «Принято. Завершаем сессию.»
