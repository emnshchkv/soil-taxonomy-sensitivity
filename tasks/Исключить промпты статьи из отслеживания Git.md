# Исключить промпты статьи из отслеживания Git

Запрос пользователя: «убери из отслеживаемого project_bacteria/AGENT_ARTICLE_PROMPT.txt и project_bacteria/AGENT_ARTICLE_STEP5_PROMPT.txt если я впишу в gitiognore папки results tasks и кое-что еще, у меня на гите они пропадут?»

Готово, когда: два указанных промпта исключены из индекса Git и добавлены в .gitignore, их локальное содержимое сохранено; git ls-files, git check-ignore и сравнение SHA256 подтверждают результат; checks/check.py возвращает 0; пользователю объяснено различие ignore, удаления из индекса и истории.
Не входит: исключение results/, tasks/ и других файлов, удаление локальных промптов, переписывание истории или git push.

## Итог
Уточнение пользователя: «пусть только промпты уберутся из отслеживания».
Два промпта исключены через git rm --cached и добавлены в .gitignore; локальные файлы сохранены, SHA256 до и после совпадают. results/, tasks/ и остальные файлы остаются отслеживаемыми.
git ls-files для промптов пуст; git check-ignore подтверждает оба правила; checks/check.py через conda qiime2-amplicon-2025.7 — код 0. [[Проверка исключения промптов статьи из Git]].
