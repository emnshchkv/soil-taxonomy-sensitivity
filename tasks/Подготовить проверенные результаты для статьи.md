# Подготовить проверенные результаты для статьи

Запрос пользователя: «приступай к шагу 4».

Контекст поручения: шаг 4 practice.md — проверка и результаты. Разобрать актуальные рисунки, выбрать материалы для будущей статьи, обеспечить перенос чисел из существующих результатов и проверку корректных/ошибочных выходов. Рукопись остаётся отдельным шагом.

Готово, когда: выбор материалов и допустимых выводов записан с источниками и знаменателями; создан воспроизводимый комплект таблиц и числовых макросов LaTeX из текущих результатов; независимая проверка принимает верный комплект и обнаруживает подмену; проверки исходного сравнения, семейственных профилей и checks/check.py проходят; отдельный INCOMPLETE полного денойзинга указан без изменения критериев; прежние научные файлы сохранены.
Не входит: повторный DADA2 или классификация, изменение исходной методики/критериев/результатов, экологические причинные выводы, новый поиск литературы, написание или восстановление рукописи, подача.

## План

Отобрать результаты и рисунки для статьи
Сформировать таблицы и числовые макросы статьи
Проверить комплект результатов для статьи

## Итог

Все три подзадачи выполнены: выбран материал с источниками/ограничениями, создан воспроизводимый комплект чисел, независимая проверка отличает верный результат от 14 видов подмены.
Комплект results/paper_step4/20261118/ содержит три подробные таблицы, 37 макросов с картой происхождения, два TeX-фрагмента и реестр четырёх PDF; все десять файлов воспроизведены побайтно.
Числовая проверка — 1520 сверок, PASS/0; 16 CLI-испытаний — PASS/0; научные проверки прошли с отдельно сохранённым INCOMPLETE/2 полного DADA2 по Kr5. 1209 прежних файлов неизменны.
Проверка чисел/ссылок самой статьи и вёрстки остаётся шагом 5: рукопись не создавалась. Статус принятия пользователем не присваивался.
