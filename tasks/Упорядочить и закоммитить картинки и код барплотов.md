# Упорядочить и закоммитить картинки и код барплотов

Запрос пользователя: «а где эи картинки и код можно найти? ты добавь их в коммиты, рассортируй по нужным папкам, пожалуйста»

Готово, когда: окончательные семейственные рисунки всех моделей и общего обзора собраны в figures/taxonomy/family/ в исходных форматах PNG/PDF/SVG; для них сохранены пути источников и SHA256, копии побайтно совпадают с проверенными оригиналами; навигация указывает код в src/, таблицы и диагностику в results/, отличает текущий набор от исторических; файлы включены в коммит ветки article; checks/check.py возвращает 0.
Не входит: пересчёт научных результатов, изменение фильтрации, повтор классификации или DADA2, продолжение статьи, включение посторонних пользовательских файлов и git push.

## План
Собрать копии окончательных рисунков, указатель кода и каталог результатов.
Проверить копии, ссылки и проект, зафиксировать подготовленные файлы в Git.

Предыдущая README результатов сохранена побайтно в BACTERIA_ONLY_20261118.md; проверенные каталоги запусков не менялись. Проверка 12 копий, 145 неизменённых файлов, архивной README и 61 ссылки — PASS/0; checks/check.py — 0.
