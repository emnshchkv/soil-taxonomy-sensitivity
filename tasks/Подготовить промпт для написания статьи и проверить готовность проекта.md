# Подготовить промпт для написания статьи и проверить готовность проекта

Запрос пользователя: «Подготовь промпт для агента, который напишет статью по этому шаблону на основе проверенных результатов проекта, с учётом всех требований и ограничений. Посмотри, есть ли что-то незавершенное в работе, что нужно сделать перед написанием статьи?»

Готово, когда: проверено актуальное состояние научных результатов и подготовки статьи; записаны оставшиеся работы и ограничения; создан самодостаточный промпт `AGENT_ARTICLE_PROMPT.txt` с источниками, требованиями шаблона, проверками, границами полномочий и условиями готовности; обе подзадачи выполнены; `checks/check.py` возвращает 0.
Не входит: написание статьи, новый научный анализ или этап 5, повторный DADA2 и классификация, публикация, изменение научной методики и защищённых файлов, оформление предметной литературы в граф.

## План
Проверить готовность результатов и материалов для статьи
Составить и проверить промпт агента для статьи
