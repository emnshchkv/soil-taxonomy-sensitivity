Готово, когда: (а) для каждого из трёх полных QZA: процесс завершился с кодом 0, qiime tools validate сообщает успех; (б) тип FeatureData[Taxonomy], ровно 3374 уникальных ID, набор точно равен rep_seq.qza, нет пропущенных или лишних ASV; (в) Confidence — конечные числа в [0,1], Unassigned сам по себе не ошибка; (г) корневое действие feature-classifier/classify_sklearn, UUID reads равен исходному rep_seq.qza, UUID classifier соответствует нужной модели, confidence=0.7 и n_jobs=1; (д) детерминированно выбраны три ASV, сверены их Taxon и Confidence с qiime tools export, сохранены ID и результат сверки; (е) повторяемая команда/скрипт проверки сохранены в src/, без изменения checks/; (ж) в results/full_classification/ сохранены точные команды, полный stdout/stderr без ручных сокращений, настоящий код процесса, время начала/окончания, UUID и SHA256 входов, моделей и результатов, таблица итогов проверок; (з) экспорты QZA размещены в work/, существующие журналы не затёрты, повторные проверки получают отдельные журналы.
