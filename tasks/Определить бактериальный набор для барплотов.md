# Определить бактериальный набор для барплотов

Готово, когда: назначения домена сверены по всем моделям, расхождения/неизвестные отдельно учтены; правило фильтрации и знаменатели будущих рисунков явно зафиксированы.
Не входит: экологическая интерпретация, переобучение или повтор классификации, подмена неназначенного ранга неизвестным доменом.
