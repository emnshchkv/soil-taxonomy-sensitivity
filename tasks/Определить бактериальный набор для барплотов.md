# Определить бактериальный набор для барплотов

Готово, когда: назначения домена сверены по всем моделям, расхождения/неизвестные отдельно учтены; правило фильтрации и знаменатели будущих рисунков явно зафиксированы.
Не входит: экологическая интерпретация, переобучение или повтор классификации, подмена неназначенного ранга неизвестным доменом.

## Итог
Домены проверены по QZA, частотам и метаданным: domain_audit.json — PASS/0, violations=[], входы неизменны.
Правило отбора и знаменатели записаны в [[Метод отбора бактериальных назначений для барплотов]]: Bacteria отдельно для каждой модели, неизвестный домен исключён и учтён; нижние неназначенные ранги сохраняются.
Результат — [[Доменные назначения и потери при бактериальном отборе]], проверка — [[Проверка доменного аудита барплотов]].
