# Сверить числа ридов независимой командой

Готово, когда: для каждого образца число ридов R1 равно `gzcat <файл R1> | wc -l`, делённому на 4, расхождение 0 — команда и результат записаны в «Итог».
Не входит: оценка качества, денойзинг.

## Итог
Команда: `gzcat data/raw/<файл> | wc -l | tr -d ' ' | xargs -I{} echo {} / 4 | bc` для каждого из 11 образцов. Расхождение с `results/read_counts_R1.tsv` — 0 у всех образцов. Проверка «Сверка числа ридов с gzcat» решена.

Принято пользователем: «Принято. Завершаем сессию.»
