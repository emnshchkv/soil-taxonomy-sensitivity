# Собрать PDF и проверить вёрстку

Готово, когда: из каталога статьи выполнены pdflatex → bibtex → pdflatex → pdflatex без неразрешённых ссылок и цитат; paper.pdf существует; основной текст занимает 2–4 страницы по границам разделов PDF, а не по общему числу страниц; все страницы отрендерены и просмотрены; таблицы и подписи читаемы, нет переполнений и пустот; обезличенный PDF не содержит автора, почты и локальных абсолютных путей.
Не входит: изменение полей, шрифтов и интервалов ради объёма, подача статьи, публикация репозитория.
