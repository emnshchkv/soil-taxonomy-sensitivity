# Подготовить промпт шага 5 по проверенным материалам

Запрос пользователя: «составь для него промпт, опираясь на наши результаты».

Контекст: написание статьи будущим агентом в заданном порядке, ограничения перед результатами, основной текст 2–4 страницы, проверяемые числа/ссылки и пометки происхождения. Последующее уточнение — литература в references/.

Готово, когда: создан отдельный промпт для будущего агента с актуальными путями, ограничениями вывода, источниками чисел/цитат, требованиями к разметке ИИ, проверке фактической рукописи и PDF; старый промпт сохранён; сама рукопись не написана.
Не входит: выполнение шага 5, восстановление старой статьи, подача, новые расчёты и поиск DOI.
